# tripwire

**Status: work in progress. Nothing here is measured yet, so there are no results to report.**

Tripwire feeds a Grok agent deliberately corrupted engineering data, measures whether it notices, and ships a fail-closed check.

The plan:

- A tool server that serves engineering data (public sources such as FAA service difficulty reports, plus synthetic work orders generated by a committed, seeded script) and can plant realistic faults on command: swapped units, stale revisions, truncated results, and writes that report success but never happened.
- A benchmark that records every planted fault and adjudicates deterministically (no LLM judge) whether the agent noticed it, acted on it, and reached the correct outcome.
- A fail-closed read-back check, measured for how much it helps and what it costs.

It reuses the planted-fault method from [sabot](https://github.com/Jott2121/sabot). Public or synthetic data only.
